# 🎨 WhimsyTheme

A tiny theme builder that turns colours into cute, usable UI themes.

WhimsyTheme lets you create a theme manually or **generate one from an image**. Upload an image, let WhimsyTheme analyse its colours, and watch them become a complete UI colour palette.

> Give it a picture. Get a theme. ✨

## ✨ Features

### 🎨 Manual Theme Builder

Fine-tune your theme with individual colour controls:

* Primary
* Secondary
* Accent
* Danger
* Success
* Warning
* Background
* Surface
* Text
* Subtext
* Border

Each colour can be edited using a colour picker or a HEX value.

### 🖼️ Generate from Image

Upload an image and WhimsyTheme analyses its colours to generate a theme.

Currently, the image analysis considers:

* **Colour frequency** → Background and Surface
* **Saturation** → Primary and Secondary
* **Lightness** → Text and Subtext
* **Colour blending** → Border
* **Background normalization** → tones down extremely saturated backgrounds
* **Accent selection** → derives an accent colour from the generated palette

Supported image formats:

* PNG
* JPG / JPEG
* WebP

Highly saturated images are gently toned down when necessary so that an image doesn't accidentally turn the entire UI into an eyeball-destroying colour bomb.

Yes, this feature was tested against a cursed Notepad++ screenshot.

### 👀 Live Preview

See the generated theme applied to a sample application interface in real time.

The preview includes:

* Navigation
* Links
* Buttons
* Cards
* Form inputs
* Warning notices
* Success notices

Theme colours are applied throughout the preview so you can see how the generated palette behaves against different UI elements.

### 🖱️ Interactive States

Buttons include themed interaction states:

* **Hover** → Accent border and glow
* **Focus** → Accent focus outline
* **Active** → Subtle press effect
* **Disabled** → Reduced opacity

Links use the generated **accent colour** and retain an underline for readability.

### 📋 CSS Generation

Switch between the live preview and generated CSS.

The generated theme uses CSS custom properties such as:

```css
--color-primary
--color-secondary
--color-accent
--color-background
--color-surface
--color-text
```

Generated component styles also make use of the theme variables, including button states, links, inputs, cards, and notices.

CSS can be copied directly from the interface.

## 🧠 How Image Theme Generation Works

WhimsyTheme currently follows a simple colour-analysis pipeline:

```text
Image
  ↓
Extract colours
  ↓
Count colour frequency
  ↓
Calculate saturation
  ↓
Calculate lightness
  ↓
Generate theme colours
  ↓
Normalize where necessary
  ↓
Apply theme
  ↓
✨ Pretty UI
```

### Background & Surface

The most frequent colours in the image are used as the starting point for the background and surface.

Extremely saturated background colours are normalized to produce a softer UI background while retaining the original hue.

### Primary & Secondary

Highly saturated colours are preferred as primary and secondary colours.

Colours that are too close to the generated background or surface are filtered out to avoid producing colours that disappear into the UI.

Maximum-saturation colours are avoided where possible so that very dark or near-black colours do not overwhelm the selection.

### Accent

The accent colour is derived from the available palette and is used for interactive elements such as:

* Links
* Button hover states
* Focus outlines
* Button hover glow

The accent can also be adjusted manually after generation.

### Text & Subtext

The background's lightness determines whether darker or lighter colours are selected for readable text.

### Border

The border colour is generated by blending the subtext and surface colours.

### Semantic Colours

Danger, success, and warning colours currently remain independent semantic colours rather than being automatically altered by image analysis.

Their existing opacity-based notice styling allows them to blend naturally with different generated backgrounds.

## 🧪 The Testing Methodology

WhimsyTheme is currently being tested using a highly scientific methodology:

1. Upload a cute image.
2. Admire the result.
3. Upload something horrible.
4. Discover what broke.
5. Fix it.
6. Repeat.
